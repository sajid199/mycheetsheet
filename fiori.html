Fiori Security Overview

SAP Fiori Security controls how users access Launchpad tiles, apps, and the OData/RFC services that power them — spanning both the Front-end (Gateway) Server and the Back-end Server.

Two common deployment models: Embedded — Gateway and backend on the same system (typical for S/4HANA) — and Hub/Central — a separate Front-end Server routing to one or more Back-end systems via system aliases and trusted RFC.

Important Transactions

  • /UI2/FLPD_CUSTLaunchpad Designer — customer catalogs & groups
  • /UI2/FLPD_CONFLaunchpad Designer — SAP delivered content
  • /UI2/FLPLaunch the Fiori Launchpad
  • /UI2/FLPCM_CUSTManage Launchpad Spaces & Pages (S/4HANA)
  • /IWFND/MAINT_SERVICEActivate/register OData service (front-end)
  • /IWBEP/REG_SERVICERegister OData service (back-end)
  • /IWFND/GW_CLIENTGateway Client — test OData calls
  • /IWFND/ERROR_LOGGateway error log
  • /UI5/UI5_REPOSITORY_LOADUpload/manage a UI5 app in the ABAP repo
  • SICFActivate ICF services (required for launch)
  • PFCGRole maintenance — assign catalogs/groups/spaces
  • /UI2/GW_APPS_LOGApp usage & performance log

Key Concepts

  • Catalog: a container of tiles & target mappings; assigned to roles, never directly to users
  • Group: a set of tiles arranged on the user's home page (classic launchpad model)
  • Space & Page: newer launchpad content model (S/4HANA 2020+) that extends/replaces groups
  • Tile: the visual launcher for an app, linked to a target mapping
  • Target Mapping: connects a Semantic Object + Action to the real app (UI5 component, WebDynpro, transaction, or URL)
  • Semantic Object: the business entity a tile represents (e.g. SalesOrder) — used for intent-based navigation

Important Tables

  • /UI2/PAGE_BUILD_CUST Custom page/tile customizing data
  • /UI2/PAGE_BUILD_PERS User personalization of pages/tiles
  • /UI2/PAGE_BUILD_DATA Merged active page data (runtime)
  • /UI2/INTEROP Front-end/back-end interoperability config
  • /UI5/UI5_REPOSITORY SAPUI5 application repository (BSP storage)
  • AGR_1251 Role authorization data (incl. S_START / S_SERVICE)

Critical Authorization Objects

  • S_SERVICE Controls execution of OData/ICF services used by apps
  • S_START Start authority for UI5 apps/tiles — auto-added from catalog
  • S_ICF Protects access to Internet Communication Framework services
  • S_RFC Front-end ↔ back-end RFC / trusted RFC communication
  • S_TCODE Needed when a tile launches a classic transaction/WebDynpro
  • S_RFCACL Trusted RFC connections in hub deployments

ICF Services to Activate (SICF)

  • /sap/bc/ui5_ui5 Serves SAPUI5 application resources
  • /sap/opu/odata Base node for all OData services
  • /sap/bc/ui2/flp Fiori Launchpad itself
  • /sap/bc/ui2/start_up Launchpad bootstrap/startup
  • /sap/public/bc Public/unauthenticated resources (icons, fonts)

Role Building Steps

  1. Catalog: identify the catalog(s) with the needed tiles in /UI2/FLPD_CUST
  2. Group/Space: add tiles to a Group (classic) or a Space & Page (S/4HANA)
  3. PFCG: add the catalog + group/space to the role's Menu tab
  4. Generate: S_START values are pulled in automatically on profile generation
  5. Backend auth: add S_SERVICE + business objects in the same/companion role
  6. Assign & test: assign the role to the user and verify in the Launchpad
Common Issues & Quick Fixes
  • Tile missing from launchpadconfirm the catalog & group/space are on the role's Menu tab, then regenerate the profile.
  • "Service cannot be reached" / 404 on openactivate the OData service in /IWFND/MAINT_SERVICE and confirm the ICF node is active in SICF.
  • 403 Forbidden after clicking a tileadd the missing S_SERVICE value for that OData service to the role.
  • Tile opens but "not authorized"run ST01/SU53 to trace the missing object — usually S_START — and add it to the role.
  • Blank/white screen on app launchre-deploy the UI5 app via /UI5/UI5_REPOSITORY_LOAD and check the browser console for failed requests.
  • Old tiles/icons after a role changeclear the Launchpad cache via /UI2/INVAL_CACHES and refresh the browser cache.
  • Personalized layout won't resetuse "Reset to Default" in User Settings, or clear the user's /UI2/PAGE_BUILD_PERS entries.
  • SSO login loop between front-end/back-endrecheck the SAML2 trust configuration and the system alias in SICF/SM59.
  • App works in backend but not via Fioricheck the target mapping's Semantic Object + Action and the system alias routing.
  • New custom catalog invisible to userscatalogs are only exposed through a role — there is no direct user-to-catalog assignment.
